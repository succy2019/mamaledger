Tech Stack (strictly follow):
Scaffold: npm create hono@latest mamaledger — select the cloudflare-pages template. This gives you Vite + Wrangler built-in; do NOT install Vite separately.
Frontend: React + TypeScript inside the same Hono project. Add @vitejs/plugin-react to vite.config.ts.
Backend: Hono.js running as Cloudflare Pages Functions in functions/api/[[route]].ts. The React SPA and the API share a single repo and a single Cloudflare Pages deploy.
Routing: React Router v7 (lazy loading) for client-side routing.
Styling: Tailwind CSS v4 with @tailwindcss/vite plugin. All design tokens in tailwind.config.ts (see Tailwind Config section below).
Fonts: Be Vietnam Pro + Plus Jakarta Sans loaded via Google Fonts in index.html.
Icons: Material Symbols Outlined loaded via Google Fonts in index.html. Render as <span className="material-symbols-outlined">{iconName}</span>.
State & Offline: TanStack Query for server state + Dexie.js (IndexedDB) for offline-first local storage and sync queue.
Charts: Recharts (lightweight, web-native).
Voice: Web Speech API (SpeechRecognition). Fallback to manual entry if unsupported.
Database: Cloudflare D1 (SQLite) with Drizzle ORM, bound to the Hono API via wrangler.toml.
Auth: Phone number + 4-digit PIN. On registration: enter phone number → create PIN → confirm PIN → save hashed PIN in Cloudflare D1. On login: enter phone number → enter PIN → verify against stored hash → issue session token (JWT stored in localStorage).
PDF Reports: jsPDF for in-browser PDF generation + Web Share API for WhatsApp sharing.
PWA: Use vite-plugin-pwa (Workbox) to make the app installable to the home screen on Android and iOS. Configure the web app manifest with: name: "MamaLedger", short_name: "MamaLedger", display: "standalone", background_color: "#f9f9f9", theme_color: "#00450d", start_url: "/", icons at 192×192 and 512×512. Register a service worker that caches all static assets and API responses for offline use.

Android install: Use the beforeinstallprompt event to show an in-app "Install App" banner (styled with design tokens). Web Speech API works in standalone PWA mode on Android Chrome.

iOS install: The beforeinstallprompt event does NOT fire on iOS. Instead, detect iOS with /iphone|ipad|ipod/i.test(navigator.userAgent) && !(window.navigator as any).standalone, and show a custom bottom sheet banner with the instruction: "Tap the Share button (⬆) in Safari, then tap 'Add to Home Screen'". Dismiss and remember via localStorage. Web Speech API (webkitSpeechRecognition) works in iOS Safari 14.5+ including when launched as a standalone PWA — but does NOT work in Chrome on iOS (Chrome iOS uses WebKit without speech API access). Show a warning if the user opens the PWA in a non-Safari iOS browser and prompt them to switch to Safari.
Deployment: Cloudflare Pages. Build command: vite build. Output directory: dist. API routes auto-deploy as Cloudflare Pages Functions from functions/. Configure wrangler.toml with D1 database binding. SPA fallback is handled by Cloudflare Pages automatically (no vercel.json needed).
